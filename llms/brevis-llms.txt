# Brevis

> Brevis is a highly efficient ZK coprocessor and zkVM that empowers smart contracts to read from full historical on-chain data across all supported blockchains and run customizable, trust-free computations. Developers build application circuits with the Brevis SDK (Go and TypeScript), specify a Data Access Module and App Contract, and receive ZK-verified or coChain-verified results on-chain. Backed by Polychain.
